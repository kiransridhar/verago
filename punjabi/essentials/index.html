Punjabi words for Everyday Essentials

Here are 15 everyday Punjabi words for everyday Essentials. Each one is written the way it sounds in English letters, then in Punjabi script. Tap 🔊 to hear it.

PunjabiEnglish
🙋 Chaahidaਚਾਹੀਦਾ Want / need
🚫 Nahin chaahidaਨਹੀਂ ਚਾਹੀਦਾ Don't want
✅ Haiਹੈ There is
❌ Nahin haiਨਹੀਂ ਹੈ There is not
🤓 Pata haiਪਤਾ ਹੈ I know
🤷 Pata nahinਪਤਾ ਨਹੀਂ I don't know
‼️ Bahutਬਹੁਤ Very / a lot
🤏 Thorhaਥੋੜ੍ਹਾ A little
👌 Sahiਸਹੀ Correct / OK
⚠️ Galatਗ਼ਲਤ Wrong / mistake
💰 Paiseਪੈਸੇ Money
📛 Naamਨਾਮ Name
🌍 Sabhਸਭ All / everything
☝️ Kehraਕਿਹੜਾ Which one
